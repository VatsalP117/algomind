# Triage labels

These strings are used by the `triage` skill when moving issues through the state machine.

| Role | Label |
|------|-------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

Defaults are used for all roles. No overrides configured.
